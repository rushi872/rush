# github

What is GitHub?

GitHub is an online platform used to store, manage, and collaborate on software projects using Git.

It allows developers to:

Create and manage repositories
Create branches
Store and track code
Make commits
Create and review Pull Requests (PRs)
Track work using Issues
Collaborate with other developers

What is a Repository (Repo)?

A repository, or repo, is a project folder stored on GitHub that contains the project's files, code, documentation, and Git history.
